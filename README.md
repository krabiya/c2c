# C2C Gift House — website demo

Online store + shop admin for **C2C Gift House**, M G Road, Gauribidanur.

- **Website:** https://krabiya.github.io/c2c/
- **Shop admin:** https://krabiya.github.io/c2c/admin

## What's inside
- `index.html` — the whole app (customer website + shop admin: billing with barcode scanner, inventory, orders, reports, labels, settings)
- `img/` — demo product photos (see "Photo credits" in the website footer)
- `vendor/` — barcode scanner ([html5-qrcode](https://github.com/mebjas/html5-qrcode), Apache-2.0), barcode labels ([JsBarcode](https://github.com/lindell/JsBarcode), MIT), UPI QR ([qrcodejs](https://github.com/davidshimjs/qrcodejs), MIT)

## Good to know
This is a demo: stock, bills and orders are saved in each device's own browser. Customer orders are sent to the shop's WhatsApp.
